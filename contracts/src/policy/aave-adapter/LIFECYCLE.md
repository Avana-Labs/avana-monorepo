# AaveAdapter lifecycle

The AaveAdapter is the borrower's only entry point: it takes the Lock, deploys and drives the wallet's PositionProxy, mints and burns vault tokens, and calls Collateralization and the RiskModule around each Aave V4 Spoke call.

## Walkthrough

Setup (Base, from 3.1 `DEP-029`, 3.2 `BOR-022`, 3.4 `WDR-045`): market 3 is a USDC/USDT Aerodrome Slipstream market on the "Aerodrome Slipstream Stable" CDP Spoke `S`; one whole vault token (10^6 units) is worth $2.00; `CF_LP = 3,120` bps; `minPledgeUsd = $10`; USDC is priced at $0.9999. Carol holds an unstaked NFT `key1` with `L = 10,000,000,000`.

1. **Carol → [`pledge`](IAaveAdapterUser.sol#L38)`(3, (integrationId, key1), now + 600)`.** First pledge, so the Adapter calls ProxyManager [`deployProxy`](../../proxy/proxy-manager/IProxyManager.sol#L75)`(Carol, S, 3)` and VaultToken [`addValidProxy`](../../vault-token/vault-token/VaultToken.sol#L115), then Collateralization [`pledge`](../../custody/collateralization/ICollateralizationAdapter.sol#L49), which custodies the NFT and returns `credited = 10,000,000,000` ($20,000). The Adapter calls VaultToken [`mint`](../../vault-token/vault-token/VaultToken.sol#L95)`(P, 10,000,000,000)` and, through PositionProxy [`execute`](../../proxy/position-proxy/IPositionProxy.sol#L59), `Spoke.supply` and `setUsingAsCollateral`. Collateral $20,000, CF-weighted $6,240. Events: [`UserProxyCreated`](IAaveAdapterEvents.sol#L16), [`CollateralSupplied`](IAaveAdapterEvents.sol#L175), [`CollateralAdded`](IAaveAdapterEvents.sol#L28). Errors: [`DeadlineExpired`](IAaveAdapterErrors.sol#L24), [`ApplicationPaused`](IAaveAdapterErrors.sol#L19) (`MintPathSuspect`), [`ApplicationFrozen`](IAaveAdapterErrors.sol#L12) (Frozen, no debt), [`UnknownMarket`](IAaveAdapterErrors.sol#L61), [`IntegrationMismatch`](IAaveAdapterErrors.sol#L67), [`SupplyIncomplete`](IAaveAdapterErrors.sol#L108), [`BackingMismatch`](IAaveAdapterErrors.sol#L104); from below `BelowMinPledge` (an $8 NFT), `TooManyRecords` (a 17th record), `AlreadyPledged`.
2. **Carol → [`borrow`](IAaveAdapterUser.sol#L65)`(3, r_USDC, 5,000e6, Carol, now + 600, 1.20e18, 0)`.** The app first read Lens `previewBorrowRecommended`: 5,673.29 USDC at HF 1.10, maximum 6,209.56 at HF 1.00. The Adapter consumes nonce 0 (`borrowNonce` becomes 1), calls RiskModule [`preBorrowCheck`](../risk-module/IRiskModuleChecks.sol#L91), Collateralization [`markIndebted`](../../custody/collateralization/ICollateralizationDebtMark.sol#L19), `Spoke.borrow` and the 5,000 USDC transfer to Carol, then [`postHealthCheck`](../risk-module/IRiskModuleChecks.sol#L117): `hf = 6,240 / 4,999.50 = 1.2481 ≥ max(1.00, 1.20)`. Event: [`Borrowed`](IAaveAdapterEvents.sol#L48). Errors: [`ZeroAmount`](IAaveAdapterErrors.sol#L34), [`NoProxy`](IAaveAdapterErrors.sol#L45), [`InvalidReceiver`](IAaveAdapterErrors.sol#L39), [`AddressIsFrozen`](IAaveAdapterErrors.sol#L123), [`BadNonce`](IAaveAdapterErrors.sol#L30); from the RiskModule `HealthFactorTooLow` (5,700 USDC gives 1.0948 < 1.20), `BreakerTripped`, `DebtPriceTooOld`, `SequencerGrace`. There is no minimum debt and no hard health floor (`hardHealthFloor = 0`).
3. **Carol → [`pledge`](IAaveAdapterUser.sol#L38) of `keyB` (`L = 2,500,000,000`, $5,000).** A top-up to her existing proxy: record 2 of 16; collateral $25,000, CF-weighted $7,800, `hf = 7,800 / 4,999.50 = 1.5602`.
4. **W2 → [`recredit`](IAaveAdapterCollateral.sol#L57)`(m, (I, key), "", now + 600)`** (Ethereum example of 3.1). After `increaseLiquidity` on the NFPM, Collateralization [`recredit`](../../custody/collateralization/ICollateralizationAdapter.sol#L109) returns `added = 2,500,000,000`; the Adapter mints and supplies them. Event: [`CollateralRecredited`](IAaveAdapterEvents.sol#L113). Errors: `NothingToRecredit`, [`ApplicationPaused`](IAaveAdapterErrors.sol#L19) under `MintPathSuspect`.
5. **Carol → [`withdraw`](IAaveAdapterUser.sol#L121)`(3, (I, keyB), 2,500,000,000, now + 600, 1.20e18)`.** With debt, the Adapter checks the pause state and freeze and calls [`preWithdrawCheck`](../risk-module/IRiskModuleChecks.sol#L103); the proxy withdraws, the Adapter calls VaultToken [`burn`](../../vault-token/vault-token/VaultToken.sol#L105) and Collateralization [`release`](../../custody/collateralization/ICollateralizationAdapter.sol#L68), which returns the NFT; `postHealthCheck` reads 1.2481. Event: [`CollateralWithdrawn`](IAaveAdapterEvents.sol#L87). Errors: [`ApplicationPaused`](IAaveAdapterErrors.sol#L19), [`AddressIsFrozen`](IAaveAdapterErrors.sol#L123), [`UnitsMismatch`](IAaveAdapterErrors.sol#L96); Aave's `HealthFactorBelowThreshold` if she withdraws `key1` instead (HF 0.3120).
6. **Anyone → [`repay`](IAaveAdapterUser.sol#L95).** 30 days later Carol's debt is 5,024.657535 USDC. She reads Lens `quoteRepayAll` = 5,029,687,935, approves the Adapter and calls `repay(Carol, 3, r_USDC, 5,029,687,935, true, now + 600)`. Aave takes 5,024,657,573 at inclusion; the proxy refunds 5,030,362 to her; `borrowCount = 0`, so the Adapter calls [`markDebtFree`](../../custody/collateralization/ICollateralizationDebtMark.sol#L32). Event: [`Repaid`](IAaveAdapterEvents.sol#L68). Errors: [`RepayExceedsMax`](IAaveAdapterErrors.sol#L84), [`DebtRemaining`](IAaveAdapterErrors.sol#L90). Any payer may call it for any borrower; it reads no pause state, breaker, freeze or price.
7. **Carol → [`collectFees`](IAaveAdapterUser.sol#L179)`(3, (I, key1), now + 600)`.** Collateralization [`collectFees`](../../custody/collateralization/ICollateralizationUser.sol#L40) has the LPVault pay 16.50 USDC and 15.95 USDT to Carol; units, supply and health factor are unchanged. Event: LPVault [`FeesCollected`](../../custody/lp-vault/ILPVaultEvents.sol#L45). Error: `NotDepositor`, `FeesRolledIn` (rolled-in AMMs).
8. **Carol → [`removeLiquidity`](IAaveAdapterCollateral.sol#L32)`(3, (I, key1), 2,000,000,000, [1,990e6, 1,990e6], now + 600, 0)`.** Debt-free, so no MarketRegistry, pause, freeze, breaker or price is read. The Adapter burns 2,000,000,000 units and calls Collateralization [`releasePartial`](../../custody/collateralization/ICollateralizationAdapter.sol#L85); the LPVault pays about 2,000 USDC + 2,000 USDT to Carol and the record keeps 8,000,000,000 units ($16,000). Event: [`CollateralReduced`](IAaveAdapterEvents.sol#L133). Errors: `PartialRemovalTooLarge` (units ≥ credited), `BelowMinimum`; with debt, `RecordBelowMinPledge` and `HealthFactorTooLow`.
9. **V → [`repayWithCollateral`](IAaveAdapterCollateral.sol#L79)** (Ethereum example of 3.3): debt 10,000 USDC, HF 1.20, units 1,500,000,000, `minDebtRepaid = 2,950e6`, `minHealthFactor = 1.30e18`. The Adapter opens a session and calls LPVaultSwap [`deleverage`](../../liquidation/lp-vault-swap/ILPVaultSwapDeleverage.sol#L32), which calls back [`deleverageRepay`](IAaveAdapterSettlement.sol#L40) (repays 2,968.505747 USDC) and [`deleverageRelease`](IAaveAdapterSettlement.sol#L59) (burns and unwinds 1,500 vault tokens); V receives 29.41 USDC; `hfAfter = 1.5735`. Event: [`RepaidWithCollateral`](IAaveAdapterEvents.sol#L156). Errors: [`NothingToRepay`](IAaveAdapterErrors.sol#L128), [`HealthFactorNotImproved`](IAaveAdapterErrors.sol#L134), `NoDeleverageSession`, `DeleverageTooSmall` (with `minDebtRepaid = 3,000e6`).
10. **LPVaultSwap → [`burnSeized`](IAaveAdapterSettlement.sol#L24)** inside a liquidation: Bob's 975 seized vault tokens are burned from LPVaultSwap's balance between `beginSeizure` and `settleSeizure`. Event: [`SeizedUnitsBurned`](IAaveAdapterEvents.sol#L102). Error: [`NotLPVaultSwap`](IAaveAdapterErrors.sol#L72). It reads no pause state, so liquidation runs in every state.
11. **Carol → [`repayAllAndWithdraw`](IAaveAdapterUser.sol#L142)** or [`withdraw`](IAaveAdapterUser.sol#L121) of the last 8,000,000,000 units closes the account; [`releaseZeroCredit`](IAaveAdapterUser.sol#L161) returns a record whose credit a seizure took to 0.
