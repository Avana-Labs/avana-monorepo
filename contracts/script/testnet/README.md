# Test networks

These scripts deploy Avana on Sepolia and Base Sepolia exactly as the local stack ([script/local](../local/README.md)) deploys its two chains. Each chain gets the same base config, world, Hub files and step sequence, and its market values come from the same source, `script/local/test-values.json`.

- `testnet.ts` runs the whole deploy of one test network. It covers every step, both Hub releases, the timelock operations and the explorer verification. A step that passed is never run again. It also publishes the feeds' rounds.
- `keys.ts` reads the signers and role addresses from a private config file outside the repository (`test-network-config.example` shows its keys). Every signer is an encrypted keystore, and no key is written anywhere.
- `verify.ts` verifies every contract a release created on the block explorer, Avana's and the test world's alike. Each is checked against its own build output and compiler settings, and the pass is safe to rerun. It is the deploy's last stage, and `testnet.ts verify` runs it alone or as a dry run. When a source file has changed since the build (its keccak256 differs from the one the artifact's metadata records), it submits the build's version from `verify-sources/`, named by that hash; the dry run lists each changed file.
- `rpc.ts` gives the deploy its RPC from the provider credentials (`ALCHEMY_API_KEY`; `QUICKNODE_ENDPOINT_NAME` and `QUICKNODE_TOKEN` for the backup), stored with `node script/local/stack.ts secrets` or set in the environment, through [packages/rpc](../../../packages/rpc/README.md). Each step starts on the healthiest provider, Alchemy first, and its URL reaches forge and cast only through their environment. A step that fails on an RPC failure (timeout, connection, rate limit, server error, stale node) runs once more on the backup: the transactions the failed attempt sent are first looked up there and waited for, and a step that had begun broadcasting continues with `forge script --resume`. A revert is never moved. `SEPOLIA_RPC_URL` or `BASE_SEPOLIA_RPC_URL`, when set, replaces the providers for that network.
- `rehearse.ts` runs the same deploy on local nodes with the networks' chain IDs, signed only by throwaway keystores.
- `testnet.test.ts` checks that a test network's config matches the local stack's in everything but its roles, release, timelock delays, gas vault and native-ETH Uniswap v4 pools. Those pools take the deployer's own test ETH, so each is seeded with $10 instead of millions (`NATIVE_V4_POOL_USD`), and a rerun applies that to a config an earlier run wrote until the world step passes. `rpc.test.ts` checks the provider choice and the step failover against mocked providers.
