This register is the internal-review view: it holds every finding as soon as a run reports it, including findings that are open. A finding that is resolved or accepted here is mirrored as a `FINDING-NNN` entry in [5.3 Audit Findings](../spec/05-verification/03-audit-findings.md), which stays the official register. The upkeep rule is in [README.md](README.md#keeping-the-record-current).

| Status | Meaning |
|---|---|
| Open — scheduled for the spec-fix pass (Q-241 onward) | The finding stands against the spec as written. Where a decision is already recorded, the Resolution column names it and the rules it changes. |
| Resolved in spec — re-verification pending | Every rule the fix changes carries the decision in the spec pages, and the finding is mirrored in 5.3; the proving check has not yet passed in a run logged in `RUNS.md` against the edited pages. It moves to Resolved in spec when that run passes. |
| Resolved in spec | The spec rule has changed and the check in "Verified by" passes against the changed rule. |
| Accepted risk | A recorded decision keeps the rule and accepts the residual risk, with the bound stated. |
| Rejected | The finding was re-examined and does not hold; the Resolution says why. |
